# ProductCatalog — OBJECT / 12

ASP.NET Core MVC оқу жобасы. Каталогта 12 демонстрациялық электроника өнімі көрсетіледі. Жоба Razor синтаксисін, контроллерден view-ге дерек жіберуді, strongly typed view, ортақ Layout және қайта қолданылатын Partial View үлгілерін тәжірибе жүзінде көрсетеді.

Интерфейс OBJECT / 12 атты ашық editorial каталог ретінде жасалған: жылы қағаз түсті фон, кобальт-көк және маржан түсті екпіндер, өнімдердің жергілікті студиялық фотолары. Оны жеке қарап, түсініп, өз қалауыңызбен өзгертіңіз.

## Қолданылған технологиялар

- C# және .NET 9 ASP.NET Core MVC
- Razor (`.cshtml`), HTML, CSS және JavaScript
- Bootstrap 5 (жергілікті файлдар)
- Dependency Injection арқылы тіркелген үлгілік каталог қызметі

## Razor және MVC талаптары

- `Models/Product.cs` — `Id`, `Name`, `Price`, `Category`, `IsAvailable` негізгі қасиеттері және валидация атрибуттары.
- `Controllers/ProductsController.cs` — каталог қызметінен өнімдерді алады, іздеу/санат/сұрыптау GET параметрлерін өңдейді және view-ге береді.
- `Views/Products/Index.cshtml` — `@model IReadOnlyList<Product>` арқылы типтелген; `@foreach` өнімдерді қайталайды, ал әр өнімді `_ProductCard` арқылы шығарады.
- `Views/Shared/_ProductCard.cshtml` — `@model ProductCatalog.Models.Product` қолданатын қайталанатын карточка. `@if/else` қоймадағы күйді көрсетеді.
- `Products/Create` беті жаңа өнімді қосады: санаттың ашылатын select тізімі, каталог фотосын таңдау, HTTPS сурет URL-ін беру немесе JPG/PNG/WEBP файлын жүктеу мүмкіндігі бар.
- Карточканың фотосын не атауын бассаңыз, өнімнің толық ақпарат беті ашылады.
- `ViewBag.CatalogIntro`, `CollectionSize`, `AvailableCount` контроллерден бетке беріледі және бетте көрсетіледі.
- `ViewData["Title"]` бет тақырыбын орнатады; `_Layout.cshtml` ішінде браузердің `<title>` мәні ретінде қолданылады.
- `Views/_ViewStart.cshtml` ортақ Layout-ты белгілейді, `_ViewImports.cshtml` модель namespace-і мен MVC Tag Helpers-ті қосады.
- Өнім мәтіндері Razor-дың әдепкі HTML encoding-і арқылы көрсетіледі.

## Жергілікті өнім фотолары

`wwwroot/images/product-studio-grid.png` — 3×4 тордағы 12 студиялық өнім фотосы. CSS әр өнімнің `Id` мәніне сәйкес тор ұяшығын таңдап, карточкада көрсетеді. Фотолар бір жергілікті asset ішінде сақталған.

## Visual Studio 2022 арқылы ашу

1. `ProductCatalog.sln` файлын Visual Studio 2022-де ашыңыз.
2. Solution ішінен `ProductCatalog` жобасын Startup Project етіп таңдаңыз.
3. **F5** басыңыз. `http` немесе `https` іске қосу профилін қолдануға болады.
4. Жобаны құрастыру: **Build → Build Solution**.

Ортада .NET 9 SDK болуы керек.

## Терминалдан іске қосу

PowerShell-де жоба бумасына кіріңіз:

```powershell
cd .\ProductCatalog-Study
dotnet restore ProductCatalog.sln
dotnet build ProductCatalog.sln
dotnet run --project ProductCatalog.csproj
```

## Сүзгілерді қолданып көру

- Іздеу жолына `Aero` немесе `Аудио` деп жазып, **ҚОЛДАНУ** батырмасын басыңыз.
- Санатты және баға реттеуін таңдағанда сүзгі автоматты түрде серверге GET сұрауын жібереді.
- Категория белгілері іздеу сөзін және сұрыптауды бірге сақтайды.
- Нәтиже табылмаса, бос күй мен бүкіл каталогқа қайту сілтемесі көрсетіледі.
- Навигациядағы **ӨНІМ ҚОСУ** сілтемесімен өнім құрып, фотосын таңдаңыз не HTTPS URL енгізіңіз. URL үшін алдын ала көрініс бар; жүктелген файлдар `wwwroot/images/uploads` бумасына кездейсоқ атаумен жазылады.

Демо деректер `SampleProductCatalog` ішінде сақталады. Дерекқорға қосылым жоқ; қолданба қайта іске қосылғанда өнімдер бастапқы үлгілік тізімге оралады.

## Оқуға арналған жұмыс

Кодты өзіңіз түсіндіріп бере алатындай қарап шығыңыз: контроллерде сұраудың қалай сүзілетінін, `ViewBag` пен `ViewData` қайда көрсетілетінін және карточка partial-ына қандай модель берілетінін қадағалаңыз. Содан кейін кемінде екі өнім қосып, бір санат атауын немесе интерфейс мәтінін өзіңіз өзгертіп, өзгерісті қайта құрастырып тексеріңіз.
